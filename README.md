# Adnan Afaq Khan — Portfolio

A simple, responsive personal portfolio website built using **HTML**, **CSS**, and **JavaScript**.

## Live Demo

Open `index.html` in any browser (no build step required).

## Features

- Sticky navigation bar with smooth scrolling
- Mobile hamburger menu (JavaScript toggling)
- Sections: **Home (Hero), About, Skills & Certifications, Experience, Contact**
- Contact form powered by **Formspree**

## Project Structure

- `index.html` — Main portfolio page (layout + content)
- `style.CSS` — Styling for the entire website (responsive + UI components)
- `script.js` — Mobile menu behavior

## How to Run Locally

1. Ensure all three files exist in the same folder:
   - `index.html`
   - `style.CSS`
   - `script.js`
2. Double-click `index.html` (or right-click → Open with your browser).
